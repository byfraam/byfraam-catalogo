by Fraam Studio — Catálogo FINAL

USO
1. Abrí index.html con Chrome/Edge/Firefox.
2. Entrá en Administrar.
3. Configurá los porcentajes de ganancia para X1, X10, X20, X50, X100, X250 y X500.
4. Configurá el redondeo y el WhatsApp.
5. Completá la información pública de by Fraam Studio y cargá el logo.
6. Cargá cada producto ingresando únicamente su COSTO: los precios se calculan solos.
7. Volvé a Catálogo para usar la tienda.
8. El cliente puede elegir cantidades, minorista/mayorista, armar el carrito y enviar el pedido por WhatsApp.

FUNCIONES
- Catálogo con búsqueda y categorías.
- Precios X1 / X10 / X20 / X50 / X100 / X250 / X500.
- Cálculo automático según porcentaje sobre costo.
- Redondeo configurable.
- Carga de imágenes.
- Carrito de compras.
- Pedido por WhatsApp.
- Información comercial y condiciones de by Fraam Studio.
- Configuración del logo y datos públicos.

IMPORTANTE
Los productos, precios y configuración se guardan en el navegador mediante localStorage. Esta versión funciona como catálogo web local. Para que los cambios estén disponibles desde cualquier dispositivo y tenga una URL pública, el siguiente paso es publicarla en un servicio de hosting estático como GitHub Pages o Cloudflare Pages y, si se necesita administración multi-dispositivo, conectar una base de datos.
